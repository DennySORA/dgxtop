**dgxtop** is a terminal GPU monitor built for NVIDIA DGX Spark: every GPU, each job's share of its memory and the whole machine on one screen, plus a record of every GPU job from start to end. It runs on any Linux machine with NVIDIA GPUs.

## New in v2.1.0

- **Memory by process.** The eight processes holding the most GPU memory each get a color, the same in the memory bars, the charts and the process table.
- **Named by what they run.** `python -m vllm.entrypoints.openai.api_server` shows as `vllm.api_server`, and `python main.py` in a `ComfyUI` folder as `ComfyUI/main`, not as `python3`.
- **Process History.** Every GPU process is recorded as a run: its runtime, peak GPU memory and RAM, GPU and CPU use, and how it ended (exit code, signal, stopped from dgxtop, OOM killer). Open a run for its full command line, working folder and charts.
- **Overview History in bars** of 1 minute to 24 hours on the local clock, kept on disk with no age limit: 24-hour bars reach back about 10 months.
- **More of the machine.** Drive temperatures; the current and maximum frequency of each kind of CPU core; the GB10's CPU cluster temperatures; the Linux kernel in the GPU view; each disk's filesystem type, free space and latency; each network interface's drops and packets; and each data source's state in Settings.
- **Clearer screens.** Gauges stay green below 50 % and turn from amber to red as they near the redline; each panel names its own keys; History is two tabs, Overview History and Process History; the process table gives each process one row.
- **`F9`** stops the selected process with SIGKILL after a confirmation, next to `K` (SIGTERM).

## Changed

- The Processes, Sources and Actions views are gone: the process table is on the Overview, and the data sources are in Settings.
- `--log-level` is removed.
- Databases written by v2.0 start empty after the upgrade (history and the log of process actions). `config.json` is kept, and settings that no longer exist in it are ignored.

## Fixed

- The installer could refuse a matching release on a busy machine.
- History could show up to a minute from before dgxtop started.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/DennySORA/dgxtop/main/install.sh | bash
```

Linux on x86_64 or aarch64 with glibc 2.34 or newer (Ubuntu 22.04, Debian 12, RHEL 9 and later), DGX Spark included; WSL 2 runs the Linux build. The installer checks the archive against `SHA256SUMS` and keeps the previous version for `./install.sh --rollback`. `dgxtop-v2.1.0.cdx.json` lists the dependencies (CycloneDX SBOM).
