**dgxtop** is a terminal GPU monitor built for NVIDIA DGX Spark: every GPU, each job's share of its memory and the whole machine on one screen, plus a record of every GPU job from start to end. It runs on any Linux machine with NVIDIA GPUs.

## New in v2.2.0

- **Total and CPU power.** Where the CPU's power can be read (powercap, or the GB10's power sensors), the header shows what the CPU and the GPUs draw together (`⚡ 615 W total`) and the CPU line shows the CPU's own power (`⚡ 370 W`). Each is left out while a part of it cannot be read, and the total is not the power at the wall socket.
- **Power in Overview History.** The total and the CPU's power are kept in every bar size and on disk, like the other Overview series. The power panel then starts with them, above each GPU's power, each with its now, average, maximum and energy.
- **Colors in 100 steps.** Gauges, chart columns and values shade from green at 0 % through amber at 50 % to red at 100 %, a color for each whole percent; nothing turns red before it is full.
- **Colored temperatures.** Every temperature reading takes the color of its share of 100 °C: the GPU and CPU lines, each core, the drives, the GPU view's thermal block and the History table.

## Changed

- `viewer.redline_threshold_percent` is retired, since level colors no longer turn red at a threshold. A `config.json` that still has it loads, the key is ignored and the next save leaves it out; `--check-config` names it. A v1 `redline_threshold` is no longer imported.

## Install this release

```bash
curl -fsSL https://raw.githubusercontent.com/DennySORA/dgxtop/main/install.sh | bash -s -- --version v2.2.0
```

Without `-s -- --version v2.2.0`, the installer takes the [latest release](https://github.com/DennySORA/dgxtop/releases/latest). Linux on x86_64 or aarch64 with glibc 2.34 or newer (Ubuntu 22.04, Debian 12, RHEL 9 and later), DGX Spark included; WSL 2 runs the Linux build. The installer checks the archive against `SHA256SUMS` and keeps the previous version for `./install.sh --rollback`. `dgxtop-v2.2.0.cdx.json` lists the dependencies (CycloneDX SBOM).
