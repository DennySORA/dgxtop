**dgxtop** is a terminal GPU monitor built for NVIDIA DGX Spark: every GPU, each job's share of its memory and the whole machine on one screen, plus a record of every GPU job from start to end. It runs on any Linux machine with NVIDIA GPUs.

## New in v2.3.0

- **Fold what you don't watch.** On the Overview, `i` and `n` fold the disk I/O and network panels to one row so the GPU processes get the rest. On Overview History, `c` `m` `u` `v` `t` `p` `i` `n` fold its panels to their title row so the others grow. Each panel shows its key, `o` unfolds everything, a click on a folded row unfolds it, and the folds are kept after a restart.
- **One GPU at a time in Overview History.** With several GPUs the GPU charts show one GPU, picked with `↑` / `↓` or a click on its name; `←` / `→` change the bar size, and `PgUp` / `PgDn` scroll charts that do not fit. The 1 h to 24 h table is gone: the charts and their bar sizes show the same.
- **Process History you can manage.** Running runs stay on top. `/` filters the runs by name or PID, older ones included; `g` / `G` jump to the top or the end; `Space` and `a` mark runs, and `d` deletes the ended ones after a confirmation, from the list and from disk. An opened run whose charts would be squeezed shows them on pages (`PgDn` / `PgUp`).
- **Pages in the GPU view.** On a smaller terminal the sections that do not fit go on pages, turned with `↑` / `↓`; `←` / `→` still switch the GPU.
- **A faster F9.** `F9` and `K` act on the row you just selected, a `y` typed before the question shows still confirms, the question and the result arrive within milliseconds, and a stopped process leaves the list as soon as it exits. The confirmation and the audit record written before the signal stay.
- **Keyboards without arrow keys.** `h` / `j` / `k` / `l` stand in for the arrows, `Ctrl-U` / `Ctrl-D` for `PgUp` / `PgDn` and `<` / `>` for `Home` / `End`; `Ctrl-B` / `Ctrl-F` / `Ctrl-A` / `Ctrl-E` move the filter's cursor. The hints show the letters.

## Changed

- In Overview History `←` / `→` step the bar size and `↑` / `↓` pick the GPU; scrolling moved to `PgUp` / `PgDn`. In the GPU view `↑` / `↓` turn pages instead of switching the GPU.
- Folding a panel writes `viewer.folded` to `config.json`, which v2.2.0 and earlier refuse. Unfold everything with `o` before going back to an earlier version.

## Install this release

```bash
curl -fsSL https://raw.githubusercontent.com/DennySORA/dgxtop/main/install.sh | bash -s -- --version v2.3.0
```

Without `-s -- --version v2.3.0`, the installer takes the [latest release](https://github.com/DennySORA/dgxtop/releases/latest). Linux on x86_64 or aarch64 with glibc 2.34 or newer (Ubuntu 22.04, Debian 12, RHEL 9 and later), DGX Spark included; WSL 2 runs the Linux build. The installer checks the archive against `SHA256SUMS` and keeps the previous version for `./install.sh --rollback`. `dgxtop-v2.3.0.cdx.json` lists the dependencies (CycloneDX SBOM).
