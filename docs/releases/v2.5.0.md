**dgxtop** is a terminal GPU monitor built for NVIDIA DGX Spark: every GPU, each job's share of its memory and the whole machine on one screen, plus a record of every GPU job from start to end. It runs on any Linux machine with NVIDIA GPUs.

## New in v2.5.0

- **Disk rows that count once.** Disk I/O lists only the devices that hold a mounted filesystem, each named first by the end of its mount point (`[/] dm-1`, `[efi] nvme0n1p1`, `[data] nvme0n1p3`), so a whole disk and its LUKS or LVM layers no longer repeat the same I/O as rows without a capacity. The title, the `R` / `W` rows and the Overview History's disk chart follow the busiest whole disk, and an LVM volume shows its drive's temperature.
- **The CPU by name on Arm.** On a DGX Spark the CPU panel names its cores, `CPU ▸ 10× Cortex-A725 + 10× Cortex-X925`, as an x86 CPU shows its model.
- **Process actions with sudo.** Started with `sudo`, dgxtop acts for the user who ran sudo, so `K` and `F9` reach that user's processes instead of being refused. `--any-user` lets a run reach every process the system allows, containers' included, as htop run as root does, under an `ANY-USER` badge; PID 1 and dgxtop's own processes stay protected.

## Changed

- More of the screen shades with its level: the disk table's `Use%` goes from green to red like a gauge, temperatures stay green up to 50 °C and fan speeds up to 50 % before they turn amber and red, both overview GPU headlines write the whole `GPU 0 │ model` in the GPU's color, and the header's `DGXTOP` is a gradient.
- There is no help screen: `?` and `F1` are no longer bound, and each panel names the keys that act on it on its title.

## Fixed

- A job holding a small share of the RAM had no color in the memory chart while its columns were lower than a row, and a share under half a cell got no cell of the bar. Every job now keeps at least one cell of the bar, and a low column of the chart is drawn a row high, split between the jobs and the system in proportion.
- `a` then `d` in the Process History deleted only the ended runs among the 200 the list carries; it now deletes every ended run the filter keeps.

## Install

```bash
curl -fsSL https://raw.githubusercontent.com/DennySORA/dgxtop/main/install.sh | bash
```

Linux on x86_64 or aarch64 with glibc 2.34 or newer (Ubuntu 22.04, Debian 12, RHEL 9 and later), DGX Spark included; WSL 2 runs the Linux build. The installer checks the archive against `SHA256SUMS` and keeps the previous version for `./install.sh --rollback`. `dgxtop-v2.5.0.cdx.json` lists the dependencies (CycloneDX SBOM).
