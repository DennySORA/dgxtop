**dgxtop** is a terminal GPU monitor built for NVIDIA DGX Spark: every GPU, the processes using it and the whole machine on one screen, with history that survives restarts. It runs on any Linux machine with NVIDIA GPUs.

## In v2.0.0

- **Every GPU at a glance.** Utilization, memory, temperature, power, clocks and fans for each GPU, with live charts.
- **Full GPU details.** Performance state and throttle reasons, clocks, memory and the memory bus, PCIe, NVLink-C2C, thermal limits, power and energy, CUDA and driver versions, NUMA and CPU affinity, P2P paths, device and firmware.
- **GPU processes.** Every process using a GPU, with its GPU, type, GPU memory, CPU and RAM. Filter, sort, and stop a process after a confirmation.
- **History.** Charts from 5 minutes to 24 hours with now, average and maximum, and each GPU's last 1, 6, 12 and 24 hours with the energy it used, saved on disk for 7 days.
- **The whole machine.** CPU usage per core, memory and swap, disk throughput and filesystem capacity, network throughput.
- **Made for DGX Spark.** How much of the GB10's unified memory GPU processes hold, its NVLink-C2C link, and a native aarch64 build.
- **Settings in the app**, each with its saved and effective value.
- **A verified installer** that checks every download and keeps the previous version for a rollback.

Upgrading from v1 never modifies `~/.config/dgxtop/config.json`: review the mapping with `dgxtop --import-legacy <path> --dry-run`, then write the v2 file with `--apply`.

## Install this release

```bash
curl -fsSL https://raw.githubusercontent.com/DennySORA/dgxtop/main/install.sh | bash -s -- --version v2.0.0
```

Without `-s -- --version v2.0.0`, the installer takes the [latest release](https://github.com/DennySORA/dgxtop/releases/latest). Linux on x86_64 or aarch64 with glibc 2.34 or newer (Ubuntu 22.04, Debian 12, RHEL 9 and later), DGX Spark included; WSL 2 runs the Linux build.
