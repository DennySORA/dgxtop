**dgxtop** is a terminal GPU monitor built for NVIDIA DGX Spark: every GPU, the processes using it and the whole machine on one screen, with history that survives restarts. It runs on any Linux machine with NVIDIA GPUs.

## In v2.0.1

dgxtop itself is unchanged from v2.0.0. Each published release is now installed and tested with the install command on Ubuntu, Debian and Rocky Linux.

## Install this release

```bash
curl -fsSL https://raw.githubusercontent.com/DennySORA/dgxtop/main/install.sh | bash -s -- --version v2.0.1
```

Without `-s -- --version v2.0.1`, the installer takes the [latest release](https://github.com/DennySORA/dgxtop/releases/latest). Linux on x86_64 or aarch64 with glibc 2.34 or newer (Ubuntu 22.04, Debian 12, RHEL 9 and later), DGX Spark included; WSL 2 runs the Linux build.
